# genko crate

## 目的
`genko` はアプリケーションのエントリーポイントとなるバイナリ crate で、ウィンドウの初期化、メニューとショートカット登録、ファイル入出力、設定ウィンドウの表示制御を担当します。

## 役割
- `Editor` エンティティと `Vim` エンティティを作成し、UI 全体を束ねる。
- 設定 (`AppSettings`) の状態に応じて通常編集モードと Vim モードを切り替える。
- 開く/保存/終了などのアプリ全体アクションを処理する。
- 設定パネル (`SettingsWindow`) を表示し、永続化済み設定を反映する。

## 処理の詳細
1. **起動時初期化**
   - `settings::init`, `editor::init` を呼び出し、グローバル設定とキーバインドを準備する。
   - メインウィンドウ生成時に `GenkoApp` を構築し、`Editor` と `Vim` を紐づける。

2. **UI と状態同期**
   - ビューポートサイズ変更時に、`Editor`/`Vim` 側へ表示サイズを通知して描画セル数を再計算する。
   - 設定の `vim_mode` 変更を監視し、入力モードを安全に切り替える。

3. **ファイル入出力**
   - `OpenFile` で選択ファイルを読み込み、`Editor` へ全文ロードする。
   - `SaveFile` でエディタ内容を取り出して UTF-8 テキストとして保存する。
   - 保存先未決定時はパス選択ダイアログを表示する。

4. **設定画面連携**
   - `SettingsWindow` は `AppSettings` を編集し、保存時に設定ファイルへ永続化する。
   - 保存後は再ロード結果を反映し、ビュー状態との整合性を保つ。
