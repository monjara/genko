# soukou crate

## 目的
`soukou` はアプリケーションのエントリーポイントとなるバイナリ crate で、ウィンドウの初期化、メニューとショートカット登録、ワークスペース操作、設定ウィンドウの表示制御を担当します。

## 役割
- `EditorController` エンティティとローカル `WorkspaceState` を束ね、UI 全体を組み立てる。
- 設定 (`AppSettings`) の状態に応じて通常編集モードと Vim モードを切り替える。
- ファイル/フォルダを開く、保存する、終了するなどのアプリ全体アクションを処理する。
- 設定パネル (`SettingsWindow`) を表示し、永続化済み設定を反映する。

## 処理の詳細
1. **起動時初期化**
   - `settings::init`, `editor::init` を呼び出し、グローバル設定とキーバインドを準備する。
   - メインウィンドウ生成時に `SoukouApp` を構築し、`EditorController` と `WorkspaceState` を紐づける。

2. **UI と状態同期**
   - ビューポートサイズ変更時に、`EditorController` 側へ表示サイズを通知して描画セル数を再計算する。
   - 設定の `vim_mode` 変更を監視し、入力モードを安全に切り替える。
   - 左ペインにワークスペースのファイル一覧を描画し、選択ファイルを開く。

3. **ワークスペースとファイル入出力**
   - `OpenFile` で単体ファイルを開き、ローカル `WorkspaceState` の active file を更新する。
   - `OpenFolder` でフォルダを走査し、左ペイン用のファイルツリーを構築する。
   - 左ペインからファイルを選ぶと、そのファイルを編集エリアへロードする。
   - `SaveFile` でエディタ内容を取り出して UTF-8 テキストとして保存する。
   - 保存先未決定時は active file または workspace root を初期ディレクトリにしてダイアログを表示する。

4. **設定画面連携**
   - `SettingsWindow` は `AppSettings` を編集し、保存時に設定ファイルへ永続化する。
   - 保存後は再ロード結果を反映し、ビュー状態との整合性を保つ。
